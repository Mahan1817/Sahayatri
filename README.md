# PhysioGhar 

This repository contains my QA testing work for the **PhysioGhar** website and mobile application.

## What's Included

* **QA Report** – Detailed findings from testing the website and mobile application.
* **Test Evidence** – Screenshots and supporting evidence for the reported issues.
* **UI/UX Recommendations** – Suggestions for improving the mobile application's usability, visual design, and overall user experience.

## Testing Areas

The application was tested for:

* Functional issues
* UI/UX and usability issues
* User workflows
* Input validations
* Incorrect or unexpected behavior
* Broken or incomplete features
* Mobile application experience
